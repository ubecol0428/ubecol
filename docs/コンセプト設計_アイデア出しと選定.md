# コンセプト設計：テーマのアイデア出しと選定

課題：「半径500mの困りごと」から始まり、たどると「県央連携」に行き着く導線を見つける

---

## 0. 前提の再確認 — ビジョンによって全体が接続した

提示されたビジョン：

> **構造で生じる機会損失をなくす。言ってもやっても無駄だとあきらめる人をなくす。**

これにより、これまで分離していた要素が一本につながります。

### 接続1：ビジョン ＝ 県央連携の本質

「市境」とは、**生活実感の上には存在しないのに、制度の上にだけ存在する構造**です。市境をまたいで生活している人が、市境のせいで受け取れていないものがある。これはまさに「**構造で生じる機会損失**」そのものです。

つまり、県央連携は「広域行政という遠いテーマ」ではなく、**ビジョンの具体例**として語れます。抽象度の問題は、順序を逆にすることで解けます。

### 接続2：ビジョン ＝ SNSをやること自体の意味

「言ってもやっても無駄だとあきらめる人をなくす」——このビジョンにおいて、SNSは告知手段ではありません。

**「言ったら、動いた」という事例を、経過ごと可視化する装置**です。媒体そのものがメッセージになる。これは、単なる活動報告アカウントとの決定的な差別化になります。

## 2. 選定基準（6項目）

| 基準 | 内容 |
|---|---|
| ① 生活実感 | 半径500mの具体的な困りごととして語れるか |
| ② 市議のスコープ | 一議員として実際に動かせるサイズか |
| ③ 県央連携への接続 | 掘っていくと自然に広域の話に行き着くか |
| ④ 当事者性 | 本人の経歴・立場と接続するか |
| ⑤ ビジョンの体現 | 「構造による機会損失」「あきらめ」を象徴するか |
| ⑥ 絵になるか | 写真・動画・図として成立するか |

## 3. 選定結果

### 【採用】3案

#### A. 部活動の地域移行 × 市境（最有力）

①◎ ②◎ ③◎ ④○ ⑤◎ ⑥◎

- **困りごと**：少子化で単独校では部活が組めない。隣の市には同じ競技をやりたい生徒がいるのに、市が違うので合同チームが組めない
- **なぜ強いか**：部活動の地域移行は現在進行形の全国的政策課題であり、市の教育委員会マターとして**市議のスコープに完全に収まる**。そして「やりたいのにできない」子どもの姿は、**構造による機会損失の最も純粋な形**
- **ビジョンとの一致度**：本件で最も高い。「あきらめさせられている人」が子どもという、最も反論しにくい対象
- **絵**：練習風景、市境の地図、当事者インタビュー。すべて成立する
- **注意**：子どもの撮影は保護者の許諾が必須。学校・教委との関係構築が前提

#### B. 市境の避難所

①○ ②◎ ③◎ ④△ ⑤◎ ⑥◎

- **困りごと**：自宅から一番近い避難所が隣の市にある。歩いて5分の施設ではなく、車で20分の施設へ行けと言われる
- **なぜ強いか**：**地図1枚で全員が理解できる**。命に関わるため反対する人がいない。自治体間の相互利用協定という具体的な解決策が既に他地域に存在し、「できるはず」を示せる
- **ビジョンとの一致度**：高い。「制度上そうなっているから」という最も典型的なあきらめの構造
- **絵**：地図の可視化、実際に歩いてみる動画。強い

#### C. 保育所の広域入所

①◎ ②○ ③◎ ④？ ⑤◎ ⑥○

- **困りごと**：住まいと職場が市をまたぐと、職場近くの保育所に預けられない。広域入所制度はあるが要件が厳しく使いにくい
- **なぜ強いか**：県央3市は通勤圏として一体化しており、当事者数が多い。毎朝の送迎時間という**数値化しやすい損失**
- **ビジョンとの一致度**：高い。特に働く親の「言っても無駄」感が強い領域
- **注意**：本人に当事者性があるかで説得力が大きく変わる

### 【保留】2案

#### D. 高度医療へのアクセス（③◎だが②△）
山口大学医学部附属病院が宇部市にあるという事実は、県央連携の必然性を説明不要にする強力な素材。ただし医療政策は専門性が高く、生半可に語ると浅さが露呈する。**専門家との連携が確保できてから着手すべき。**

#### E. 高校生の通学・交通（①◎だが②△）
生活実感は最強クラス。ただし公共交通は事業者・県・国が絡み、一議員が短期で動かすのは困難。**「すぐには勝てないが、長く言い続ける価値のあるテーマ」**として第2フェーズ向き。

### 【不採用】7案

| # | 不採用理由 |
|---|---|
| 6. 図書館等の相互利用 | 旗としては小さすぎる。**ただし「最初の一勝」の題材としては最適**（後述） |
| 7. 就職情報の分断 | 行政より民間・大学がやるべき領域。市議のスコープと合わない |
| 8. 移住施策の競合 | 行政側の課題であり、市民の困りごとではない |
| 9. 空港の象徴性 | 市民の生活課題ではない。シンボル・比喩としてのみ有効 |
| 10. ゴミのルール差 | 連携の必然性が弱く、不便の度合いも小さい |
| 11. 商業流出 | 連携ではなく競合の話になり、県央連携の論理と噛み合わない |
| 12. 病児保育・夜間救急 | Dと同じく医療の専門性の壁。ただしDより生活実感は強く、将来的な再検討候補 |

## 4. 選定を踏まえた構成案

### 4-1. コンテンツの3層構造

| 層 | 内容 | 頻度の目安 |
|---|---|---|
| **表層：日常** | 現場の活動、人との出会い、素の姿 | 高頻度。人柄と継続性の証拠 |
| **中層：市境シリーズ** | 「これ、市境のせいです」を1テーマずつ | 定期。旗の一貫性をつくる |
| **深層：言ったら変わった** | 小さな案件を1つ拾い、経過を最後まで追う | 低頻度・長期。ビジョンの実証 |

### 4-2. 「最初の一勝」を設計する

深層の第1弾には、**不採用にした「図書館・体育館の相互利用」が最適**です。

理由：旗としては小さいが、だからこそ**実際に動かせて、結果が出て、期間が短い**。「言ったら変わった」を最初に成立させることが、ビジョンの信憑性を決めます。大きなテーマから始めて何も動かないと、あなた自身が「言っても無駄」の証拠になってしまいます。

**小さく勝ってから、大きく張る。** 順序はこれ以外にありません。

### 4-3. 全国向けの共感軸

「地方で、行政と組んで、実際に動かしている若い経営者」というリアリティ。ここは狙って作るのではなく、中層・深層の副産物として自然に発生させるのが健全です。全国向けに最適化した瞬間、地元の解像度が落ちます。
