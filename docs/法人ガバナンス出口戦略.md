# 法人ガバナンス：出口戦略の検討

前提：一人法人の代表として宇部市と包括連携協定のもと活動 → 2030年 山口市議会議員選挙 → 39歳の年 山口市長選挙

> **免責**：公開情報にもとづく整理であり、法的助言ではありません。実行前に司法書士・弁護士および山口市選管への確認を行ってください。

---

## 1. 先に押さえるべき法的制約

出口戦略を考える前に、**選択肢の幅を決めてしまう規定**が2つあります。

### 1-1. 議員の兼業禁止（地方自治法 92条の2）

議会の議員は、**当該普通地方公共団体に対し請負をする者**、および**主として同一の行為をする法人の役員**（無限責任社員、取締役、執行役、監査役またはこれらに準ずべき者、支配人、清算人）であってはならない。

令和4年12月の改正（令和5年3月1日施行）で2点変わりました。

1. **「請負」の定義が明確化**：「業として行う工事の完成若しくは作業その他の役務の給付又は物件の納入その他の取引で当該普通地方公共団体が対価の支払をすべきもの」
2. **緩和**：政令で定める額（**年間300万円**）の範囲内であれば請負が可能に

**ただしこの300万円の緩和は「個人による請負」を対象としたものであり、法人役員としての兼業禁止が緩和されたわけではありません。** ここを取り違えると設計を誤ります。

法人側の判定基準は「**主として**同一の行為をする法人」かどうか。判例上、その法人の業務の主要部分が当該自治体との請負で占められているかで判断されます。つまり **「山口市案件が法人の主要部分か」** が分岐点です。

### 1-2. 長（市長）の兼業禁止（地方自治法 142条）

市長については**より厳格**です。300万円の緩和規定はありません。当該自治体に対し請負をする者、および主として同一の行為をする法人の役員は、市長になれません。

### 1-3. 導かれる構造的な罠

ここから、計画に内在する矛盾が見えます。

> **「山口市に事業を展開していく」計画を成功させるほど、山口市議・山口市長の兼業禁止に接近する。**

山口市からの受託が育つほど、法人は「主として山口市に対し請負をする法人」に近づきます。事業の成功が、政治的資格を削る。**しかも39歳の市長選では142条が適用され、逃げ場がさらに狭くなります。**

これは意思や誠実さで解決できる問題ではなく、**設計で回避するしかない構造**です。

## 2. 出口戦略のオプション

### O-1. 代表・役員を退任し、法人は存続させる

| | |
|---|---|
| 効果 | 兼業禁止をクリア。事業は継続し、実績も残る |
| 課題 | **一人法人であるため、後継者が存在しない**。採用・育成が事業計画そのものになる |
| 所要期間 | 現実的に3〜5年。2030年に間に合わせるなら**着手は今** |
| 適性 | ◎ 本命候補 |

### O-2. 事業譲渡・法人ごと第三者へ承継

| | |
|---|---|
| 効果 | 政治と事業の分離が最も完全。利益相反の疑念が構造的に消える |
| 課題 | 承継先の確保。宇部市との包括連携協定の扱い。あなたの「実績の源泉」が他者のものになる |
| 所要期間 | 2〜3年 |
| 適性 | ○ O-1が不調のときの代替 |

### O-3. 「山口市から受託しない」事業設計に固定する

| | |
|---|---|
| 効果 | 役員のまま議員になれる可能性を残す |
| 課題 | 「山口市に展開する」計画と正面から矛盾するように見える |
| 突破口 | **「山口市から対価を受け取らない形で山口市に関わる」設計は可能**：民間資金による事業、山口県からの受託で山口市を舞台にする、他市からの受託、市民活動としての関与、企業協賛、大学・NPOとの共同事業など |
| 限界 | 市長選（142条）では結局この設計だけでは足りない |
| 適性 | ◎ 2030年までの**設計方針**として有効 |

### O-4. 法人を休眠・解散する

| | |
|---|---|
| 効果 | 完全にクリア |
| 課題 | 損失が最大。宇部市との協定を自ら手放し、ビジョンの実行主体を失う |
| 適性 | △ 最終手段 |

### O-5. 政治活動を別の器（政治団体）に完全分離する

これは**出口戦略ではなく、前提条件**です。選択の余地はありません。

- 政治資金規正法上の政治団体を設立し、政治活動に関する収支はすべてそちらで処理する
- 法人の資金・備品・車両・通信手段・SNSアカウントを政治活動に使わない
- 会計を完全に分離し、按分が必要なものは基準を文書化する
- 法人の事業として行うイベントと、政治活動としての集会を、記録上も明確に分ける

**やらなかった場合、後年になって必ず問題化します。** そして遡って直すことはできません。

## 3. 推奨シナリオ（段階的撤退）

| 時期 | 実施事項 |
|---|---|
| **即時** | O-5（政治団体の設置と会計・資産の完全分離）。SNS開始と同時に着手 |
| **〜2027年** | O-3を事業設計の方針として固定。山口市への関わり方を「受託以外」で組み立てる |
| **2027〜2029年** | O-1に着手。後継者の採用・育成。法人を一人依存から外す |
| **2030年 選挙前** | 代表退任、または受託構成の確認。山口市選管へ事前照会 |
| **市長選まで** | O-1またはO-2を完了。142条の適用に耐える状態にする |

## 4. 見落とされがちな論点

### 4-1. 宇部市との包括連携協定の扱い

協定の相手方である宇部市には、**政治的中立性の観点からの立場**があります。あなたが政治的立場を明確にした時点で、宇部市側が協定の継続を再検討する可能性は現実的にあります。

これは公選法の問題ではなく信頼関係の問題であり、**SNSでの公開より前に、直接伝えるべき相手**がいることを意味します。SNSでの発信開始は、関係各所に対する事実上の意思表明として機能します。順序を誤ると回復できません。

### 4-2. 一人法人であること自体が、ビジョンとの矛盾

最も本質的な指摘をします。

**「構造で生じる機会損失をなくす」「言ってもやっても無駄だとあきらめる人をなくす」**——これがビジョンであるならば、**あなたの法人が、あなた一人にしか依存していないという事実は、そのビジョンに反しています。**

あなたが抜けた瞬間に事業が止まる組織は、あなたという個人に機会が集中し、他の誰も担い手になれない構造そのものです。そして政治に行けば、あなたは必ず抜けます。

裏を返せば、**後継者をつくるプロセス自体が、ビジョンの最も強い実証になります。** 「自分がいなくても回る組織をつくる」ことは、出口戦略であると同時に、最良のコンテンツです。

### 4-3. 逆説

出口戦略は「政治のために事業を畳む」話ではありません。**「あなたがいなくても続く事業」を作れたかどうかが、あなたの経営者としての実績であり、有権者に対する最大の証拠になります。**
