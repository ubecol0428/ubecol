# SNS運用における公職選挙法リスク整理

対象：2030年 山口市議会議員選挙への立候補を想定した、個人SNSアカウントの平常時運用

> **免責**：本資料は公開情報にもとづく整理であり、法的助言ではありません。
> 実際の運用開始前に、**山口市選挙管理委員会**（および必要に応じて弁護士）への確認を必ず行ってください。
> 特にグレー領域は、選管への事前照会で「やってよい形」に落とし込むのが最も安全かつ低コストです。

---

## 0. 大前提：規制の「スイッチ」はいつ入るか

SNS運用で最も重要な構造的理解は、**規制の起点が「立候補届出」ではない**という点です。

| 規制 | 適用が始まるタイミング | 意味 |
|---|---|---|
| 事前運動の禁止（法129条） | 常時（選挙運動期間外はすべて対象） | 「選挙運動」に該当する行為をした瞬間にアウト |
| 寄附の禁止（法199条の2） | **「公職の候補者となろうとする者」に該当した時点** | 出馬の意思が客観的に認められれば適用される |

つまり、**「2030年に山口市議選に出ます」とSNSで表明した瞬間、寄附禁止のスイッチを自分で入れることになります。**
これは避けるべきという意味ではなく、「いつスイッチを入れるかは戦略的に選べる」という意味です。

なお、表明していなくても、客観的に立候補の意思が推認される状況であれば「なろうとする者」に該当し得ます。
安全side に倒すなら、**運用開始時点から寄附禁止ルールを自分に適用しておく**のが実務的です。

## 1. 【グリーン】問題なく発信できるもの

いずれも「特定の選挙における特定の候補者の当選を目的とする行為」ではないため、選挙運動に当たりません。

| # | 内容 | OKである理由 |
|---|---|---|
| G-1 | まちづくり活動・法人事業の現場報告（写真・動画・レポート） | 社会活動の記録であり、選挙運動でも政治活動でもない |
| G-2 | 政策・理念の発信（「地域交通をこうすべき」等） | 「政治活動」は期間の制限なく自由。特定選挙・投票依頼を含まなければ選挙運動に当たらない |
| G-3 | 経歴・自己紹介・価値観・人柄の発信 | 同上。人物理解を促す情報提供にすぎない |
| G-4 | 他者・他団体のイベント告知や紹介 | 自身の当選を目的としない情報発信 |
| G-5 | オンライン意見交換会・勉強会の開催（無料） | 政治教育のための集会は明示的に許容されている領域。ただし飲食提供や実費超の負担は別途注意（R-5参照） |
| G-6 | インターネット上での年賀・時候のあいさつ | 法147条の2が禁じるのは「あいさつ状」の頒布であり、ネット上の挨拶は対象外と解されている。**紙の年賀状・電報を選挙区内に出すのはNG** |
| G-7 | 有権者・支援者からのコメント返信、DMでの対話 | ネット選挙運動解禁（2013年）により、ウェブサイト等を用いた発信は広く認められている |

## 2. 【イエロー】グレー。設計と記録で守るべきもの

| # | 内容 | リスクの所在 | 対処 |
|---|---|---|---|
| Y-1 | 「2030年 山口市議選に立候補予定」とプロフィールに書く | 表明のみなら直ちに違法ではないが、「応援よろしく」「一票を」が加わると事前運動に直結。加えて寄附禁止のスイッチが入る | 表明の時期を戦略的に決める。表明するなら、投票依頼を想起させる語を一切入れない |
| Y-2 | 選挙が近づいた時期の投稿量・露出の急増 | 客観的に「選挙運動」と評価されやすくなる。時期・内容・態様から総合判断される | 平常時から一定量を継続し、直前だけ跳ね上げない。**習慣化そのものが法的な防御になる** |
| Y-3 | Instagram / Facebook などの**有料広告** | 選挙運動用の有料ネット広告は原則禁止（法142条の6）。平常時の政治活動としての広告は可能だが、事前運動と評価されれば違法 | 投票依頼・特定選挙への言及を含む広告は打たない。選挙期間中は出稿停止 |
| Y-4 | フォロワーへの一斉DM・メール配信 | SNSのDMは「ウェブサイト等」として扱われる一方、**電子メールによる選挙運動は候補者・政党等に限定**（法142条の4）。境界が曖昧 | 一斉配信を仕組みとして持つ場合は、事前に選管へ照会 |
| Y-5 | 支援者・外部業者に投稿制作を手伝ってもらう | 選挙運動の対価としての報酬提供は買収罪（法221条）のリスク | 平常時の業務委託として契約書・請求書を残す。選挙運動期間に入ったら扱いを切り替える |
| Y-6 | 他候補・現職への批判的言及 | 事実に反すれば虚偽事項公表罪（法235条）、名誉毀損のリスク | 事実と評価を分ける。裏取りできない情報は出さない |
| Y-7 | 支援者から「頑張って」等のコメントが付き、それを固定・拡散する | 自身の投票依頼と評価される余地 | 第三者コメントの引用・拡散は慎重に |

## 3. 【レッド】明確にやってはいけないもの

| # | 内容 | 根拠 | 理由・帰結 |
|---|---|---|---|
| R-1 | 選挙期間外の投票依頼（「一票をお願いします」「必ず投票へ」＋特定選挙・自分） | 法129条（事前運動の禁止） | 選挙運動は公示・告示日から投票日前日までに限られる。SNS投稿は証拠として永久に残る |
| R-2 | **選挙区内（山口市）にある者への寄附**：祝儀・香典・差し入れ・飲食のおごり・賞品提供・祭りやイベントへの協賛金・花輪・寸志 | 法199条の2 | 名義を問わず禁止。罰則（法249条の2）に加え、**当選無効・公民権停止**もあり得る最重量級のリスク。例外は政党・政治団体、親族、政治教育集会の必要やむを得ない実費補償のみ |
| R-3 | 寄附行為が写り込んだ写真・動画の投稿 | R-2に同じ | 投稿そのものが違反の証拠になる。**「撮ってよい絵／撮ってはいけない絵」の線引きが必要な理由がこれ** |
| R-4 | 「誰に投票する？」等のアンケート・投票スタンプの実施と結果公表 | 法138条の3（人気投票の公表禁止） | 投票方式による当落予想の公表は何人も禁止。**Instagramストーリーズの投票スタンプは特に事故りやすい** |
| R-5 | 選挙運動に関する飲食物の提供 | 法139条 | 湯茶および通常用いられる程度の菓子を除き禁止。イベント運営時に要注意 |
| R-6 | 18歳未満に選挙運動をさせる（撮影・拡散の依頼を含む） | 法137条の2 | 若い協力者を巻き込む場面で発生しやすい |
| R-7 | 経歴・実績の虚偽・誇張表示 | 法235条、法235条の5 | SNSのプロフィール欄・肩書きの盛りすぎが該当し得る |
| R-8 | 選挙期間中の選挙運動用有料ネット広告 | 法142条の6 | 候補者個人による出稿は禁止 |

## 4. 選挙区が「山口市」であることによる特殊論点

本件は **活動拠点が宇部市、選挙区が山口市** という構造のため、通常と異なる注意点があります。

### 4-1. 寄附禁止の地理的範囲
法199条の2が禁じるのは「**当該選挙区内にある者**」への寄附です。したがって形式的には、宇部市内での差し入れ等は直接の規制対象外となり得ます。

ただし、
- 山口市在住者が宇部のイベントに参加している可能性を常に排除できない
- SNSで公開する以上、地理的な線引きは第三者から見えない
- 「宇部ではOK」という運用は、外形的に説明しづらい

以上から、**全域で同一のルール（＝寄附は一切しない）を自らに課すのが安全かつ説明可能**です。

### 4-2. 被選挙権の居住要件（法的なデッドライン）
山口市議会議員選挙に立候補するには、投票日時点で
1. 満25歳以上
2. **引き続き3か月以上、山口市に住所を有する**（＝山口市の選挙人名簿に登録される）

ことが必要です。加えて2020年の法改正により、**居住実態に関する宣誓書の提出**が求められ、虚偽と判明した場合は30万円以下の罰金の対象となります。住民票の移動だけでは足りず、**客観的な居住実態**が問われます。

→ 2030年の投票日から逆算し、**遅くとも3か月以上前**には山口市への転居・居住実態の確立が完了している必要があります。これはSNS戦略ではなくライフプランの制約であり、発信内容の設計より先に確定すべき事項です。

## 5. 運用ルールへの落とし込み（チェックリスト）

投稿前に毎回確認する項目として：

- [ ] 投票依頼を想起させる表現（一票、当選、応援よろしく＋選挙名）が入っていないか
- [ ] 写真に、差し入れ・祝儀・寸志・協賛・飲食提供の場面が写っていないか
- [ ] 未成年が選挙運動的な文脈で写っていないか（本人・保護者の許諾も別途必要）
- [ ] 肩書き・実績の記載に、事実として裏付けられないものがないか
- [ ] アンケート機能で当落・支持を問う設問になっていないか
- [ ] 他者の顔・氏名・所在が特定される情報に、本人の許諾が取れているか

### 保存ルール
- 投稿は削除しても第三者のスクリーンショットは残る。**「後で消せばいい」は成立しない**
- 投稿前チェックを通していない素材は公開しない
- 判断に迷った素材は「保留フォルダ」に置き、選管照会後に判断する
