# アカウント名・プロフィール設計

参照：`SNS要件定義.md`（コンセプト＝「地域と関わる私を発信する。地域を発信する発信者にはならない」）

## 1. リサーチで確認できた原則

影響力のあるアカウントの運用解説・事例から共通して確認できた点。

| # | 原則 | 内容 |
|---|---|---|
| 1 | **「名前欄」と「ユーザーネーム」は役割が違う** | ユーザーネームは識別子（英数字・重複不可）。**名前欄は検索対象になるキーワード枠**。両者を同じ発想で埋めるのは機会損失 |
| 2 | **名前欄に本名＋職業を置くと信頼性が上がる** | 本名と何をしている人かを明示することでアカウントの信頼性が上がり、近い関心層からのフォローを得やすい |
| 3 | **プロフィール文は150文字。「誰に」「何を」を明示する** | 何のアカウントか3秒で分からないものはフォローされない |
| 4 | **ユーザーネームはフォロワーが少ないうちに確定させる** | 後から変更は可能だが、育ってからの変更は混乱とリンク切れを招く。**最初に決め切る** |

政治家個人のInstagram活用については、無名の新人がポスターからInstagramへ流入させて当選した事例など、地方選での有効性を示す報告が複数ある。ただし**具体的な個人アカウントの名称やフォロワー数は、公開情報として信頼できる形で確認できなかったため、本資料では個別事例名を挙げない。** 上記は運用原則として一般化できる範囲に留めている。

## 2. 本件固有の設計原則

一般論をそのまま適用すると、コンセプトと衝突する箇所がある。以下で調整する。

### 原則A：肩書きは「何を発信するか」ではなく「何をしている人か」を書く

セオリー通りに「地域＋ジャンル」を名前欄に置くと、**地域を発信するアカウントに見えてしまう。** これはコンセプトに反する。

- ✕ 「宇部のまちづくり情報」 → 地域が主語になる
- ○ 「まちづくりをしている◯◯」 → 私が主語

**判定基準は要件定義と同じ。主語が「私」であること。**

### 原則B：地名は「市」ではなく「県」で書く

現在の活動拠点は宇部市、将来の出馬先は山口市。**名前欄に市名を固定で入れると、2030年に書き換えが必要になり、しかもその書き換え自体が意図を露呈する。**

「山口県」であれば、宇部市も山口市も、県央連携の文脈もすべて含む。**今も将来も書き換えが不要な唯一の粒度。**

### 原則C：ユーザーネームは本名ローマ字を原則とする

- 有権者は本名で検索する。将来の政治フェーズで最も効くのは検索性
- ハンドルネームは、政治フェーズに入った瞬間に信頼性を損なう
- 数字の羅列や意味不明な文字列は避ける。取得済みで使えない場合は、末尾に活動領域や地域の語を足す

### 原則D：政治を想起させる語を一切入れない

「議員」「政治」「選挙」「立候補」はもちろん、「未来をつくる」「変える」といった政治的スローガンに近い語も避ける。**出馬表明のスイッチを早く入れないことが、要件定義上の前提。**

## 3. 設計テンプレート

### ユーザーネーム

```
第1候補： <名>_<姓>            例）taro_yamaguchi
第2候補： <名>.<姓>            例）taro.yamaguchi
第3候補： <名><姓>_yamaguchi   （県名を添える。市名は入れない）
```

### 名前欄（表示名）

```
<本名>｜<肩書き>／山口県
```

肩書きの候補（いずれも「私が何をしている人か」を述べるもの）：
- まちづくり
- 地域プロジェクト
- まちづくり会社 代表

**「代表」を入れるかは判断が要る。** 信頼性は上がるが、法人と個人の距離が縮まる。法人ガバナンス上の分離（`法人ガバナンス出口戦略.md` O-5）を進める方針を踏まえると、**当面は肩書きに法人名を出さないほうが整合する。**

### プロフィール文（150文字以内）

構成は4行。

```
1行目： 何者か（肩書き＋活動圏）
2行目： 何をしているか（具体・固有名詞）
3行目： どこから来たか（経歴の一行）
4行目： このアカウントに何があるか
```

## 4. ドラフト2案

### 案A：事実型（信頼性を優先）

```
山口県でまちづくりの仕事をしています
▶ 宇部市と包括連携協定／◯◯事業を運営
▶ 山口市で育ち、福岡での修業を経てUターン
現場と、その裏側の判断を残していきます
```

- 強み：肩書きより先に「協定」という検証可能な事実が来る。信頼性が高い
- 弱み：やや硬い。人柄が伝わりにくい

### 案B：人柄型（親しみやすさを優先）

```
まちづくりの会社をやっています／山口県
うまくいったことより、迷ったことを書きます
▶ 宇部市と包括連携協定／◯◯を運営
▶ 山口市育ち → 福岡 → Uターン
```

- 強み：2行目が三本柱の「柱B（思考）」を宣言している。**このアカウントが活動報告ではないことを最初に示せる**
- 弱み：実績の提示が後ろに下がる

**推奨は案B。** 差別化要素は「まちづくりをしていること」ではなく「その判断過程を見せること」にあるため、それを冒頭で宣言する価値がある。

## 7. 確定稿（リサーチ反映版）

### 7-1. リサーチで確認できた事実

公開情報から確認できた範囲。いずれも報道・行政・大学の公式発表に基づく。

| 項目 | 内容 |
|---|---|
| 会社 | 株式会社UBE COL（ウベカレ）。2023年4月設立。山口大学の医学部・工学部の学生5人が中心となって設立 |
| 前身 | 学生団体「Ube col.」。2022年11月設立、山口大学公認サークル。経済学部・医学部・工学部のメンバーで構成 |
| ビジョン | 「創るを興す」。地域の若者・学生による起業と新規事業を次々に生み出すこと |
| 協定 | 2023年5月、宇部市と「若者による未来共創」に関する包括的連携協定を締結。**宇部市が学生起業の会社と協定を結ぶのは初** |
| 連携事項 | 市の若手職員と大学生の意見交換会、フードロス事業など |
| **本人の実績** | 学生団体Ube col.の代表の一人（下川拓斗氏と共同）として、2024年3月17日に東京大学で開催された「チャレンジ！！オープンガバナンス2023」で**2つの賞を受賞**。提案は、地域貢献に関心のある学生が仲間と機会に出会える仕組みにより、宇部市の魅力と市民の生活満足度を高めるもの |
| 先代代表 | 平井貴大氏。広島市出身、早稲田大学卒。放送局の記者を経て山口大学医学部へ。2025年4月に宇部市の学生活躍戦略補佐官に任命 |

### 7-2. 物語の修正点

本人の自己申告は「先代が立ち上げた会社に、代表として戻ってきた」であった。

しかし公開情報によれば、**本人は学生団体Ube col.の代表の一人として東京大学で受賞している。** つまり「他人がつくった会社を継いだ」ではなく、**「自分も関わっていた団体が会社になり、その代表として戻った」**が実態に近い。

**謙遜は美徳だが、発信においては実績を捨てる行為になる。** 事実の範囲で、関わっていたことは書いてよい。

### 7-3. 社名を出さない判断について

「社名を出さない」という方針には正当な根拠がある（会社を個人の政治的資産に見せない。法人ガバナンス上の分離方針と整合する）。

**ただしコストがある。**「宇部市と包括連携協定」という最強の信用記号は、社名なしでは第三者が検証できない。**裏の取れない実績は、実績として機能しない。**

なお、UBE COLは宇部市公式サイト、宇部日報、山口新聞、山口大学公式サイトに既に掲載されており、検索すれば数秒で辿り着く。**隠す実益は乏しい。**

**折衷案（採用）：名前欄には社名を出さない。プロフィール本文には「宇部市と包括連携協定」という事実だけを書く。**
看板にはしないが、隠しもしない。検証したい人は自力で辿り着ける。

### 7-4. 名前欄（表示名）

```
村田照真｜山口でまちづくり
```

「山口」は県とも市とも読める。**将来の書き換えが不要になる曖昧さを、意図的に残している。**

代替案：`村田照真｜まちづくり／山口県`（検索性をより重視する場合）

### 7-5. ユーザーネーム

読みは「しょうま」。

```
第1候補： shoma_murata
第2候補： murata_shoma
第3候補： shoma.murata
```

**注意：** 公開資料の一部で「Terumasa」と英字表記されている例がある。検索性の観点から、**本人が使う表記を一つに統一する**こと。

### 7-6. プロフィール確定稿（3案）

#### 案A：物語型

```
23歳／宇部でまちづくりの会社をやっています
学生時代にいた団体へ代表として戻るため、新卒1年で福岡から帰りました
▶ 宇部市と包括連携協定
これから山口市にも広げます
うまくいった話より、迷った話を置いていきます
```

#### 案B：実績型

```
23歳／宇部でまちづくり
新卒1年で福岡から戻り、学生時代にいた団体の代表になりました
▶ 宇部市と包括連携協定
▶ 東大「オープンガバナンス2023」2部門受賞
これから山口市にも広げます
```

#### 案C：地元密着型（推奨）

```
23歳／小郡育ち、いま宇部でまちづくり
学生時代にいた団体へ代表として戻るため、新卒1年で福岡から帰りました
▶ 宇部市と包括連携協定
これから山口市にも。迷った話も置いていきます
```

**推奨は案C。**

- **「小郡育ち」の4文字が、学歴の羅列より効率よく地元の証明になる。** 山口市の有権者には一発で伝わり、県外の人には人物の背景として自然に読める
- 2行目が「辞めた話」ではなく「戻った話」になっている。**同じ事実で印象が正反対になる箇所**
- 3行目が検証可能な事実
- 4行目が進行形かつ未完。「続きが見たい」を作り、同時に2030年への布石になる

### 7-7. プロフィールに書かないもの（初期）

| 項目 | 理由 |
|---|---|
| 山口高校 生徒会長 | 初対面で出すと自己PRに見える。いずれ効くが今ではない |
| 学校名の羅列 | 全国のフォロワーには意味がなく、地元向けには「小郡育ち」で足りる |
| オープンハウスの社名 | 「1年で辞めた」に読点が集まる。**辞めた話ではなく戻った話にする** |
| 株式会社UBE COL の社名 | 7-3の方針による |
| 東大受賞（案A・C） | 事実だが、初期は「実績の人」より「進行中の人」として見せるほうが訴求する |

**ただし上記はすべて、初投稿・ハイライト・投稿本文では使ってよい。** プロフィールの150文字に入れないというだけである。
